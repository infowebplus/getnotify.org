# User guide overview

GetNotify helps you send WhatsApp notifications to your customers and team. This guide covers the dashboard and core workflows.

## Getting started

1. [Create an account](https://getnotify.org/register) at getnotify.org.
2. Log in to the [dashboard](https://dashboard.getnotify.org).
3. Complete onboarding (e.g. connect your phone number, configure WhatsApp Business API).
4. Add contacts and send your first message.

## What you can do

- **Contacts** — Add or import contacts, organize them in segments.
- **Messages** — Create and send WhatsApp notifications (templates or custom).
- **Schedule** — Schedule messages for later.
- **API** — Use the API for automation; manage API keys in the dashboard.
