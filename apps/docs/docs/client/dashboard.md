# Dashboard

The GetNotify dashboard is where you manage your account, contacts, messages, and API keys.

## Log in

1. Go to [dashboard.getnotify.org](https://dashboard.getnotify.org) (or use **Log in** on getnotify.org).
2. Enter your email and password.
3. You can also use **Log in** from the [marketing site](https://getnotify.org) — it redirects you to the dashboard.

## Main sections

- **Home / Overview** — Summary of recent activity and quick actions.
- **Contacts** — Add, edit, and segment contacts.
- **Messages** — Create, schedule, and send WhatsApp notifications.
- **API keys** — Create and manage keys for API access.
- **Settings** — Account, billing, and preferences.

## API keys and developer access

API keys and message sending are managed in the dashboard. If you integrate via the API, generate a key under **API keys** and use it as described in the [API authentication](/api/authentication) docs.
